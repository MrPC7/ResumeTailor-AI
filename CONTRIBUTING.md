# Contributing to ResumeTailor AI

Thanks for your interest! Here's how to contribute:

## Reporting Bugs
Open an issue with steps to reproduce, expected vs actual behavior, and your OS/Python/Node versions.

## Suggesting Features
Open an issue with the feature idea and why it'd be useful.

## Sending PRs
1. Fork the repo
2. Create a branch: `git checkout -b feat/your-feature`
3. Make your changes and test locally
4. Open a PR against `main` with a clear description

## Code Style
- Backend: follow existing FastAPI patterns, use Pydantic models
- Frontend: TypeScript strict mode, shadcn/ui components preferred
